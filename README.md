# Mini_Project
SportsSight AI - An AI-powered platform tailored for athletes and coaches. 

Key Features: 

1. Video Analysis & AI Feedback: Athletes can easily upload videos of their sports performance. The AI model automatically detects movements, highlights mistakes, and provides detailed actionable feedback for performance improvement.
2. Coach-Athlete Connectivity: Coaches can log into the platform, view a structured ranking of athletes based on performance metrics, and contact them directly.
3. Streamlined Scouting: Eliminates the hassle of traditional searching by bridging the gap between talent and mentorship on a single dashboard.

Backend powered by Firebase for secure authentication and real-time database management.
